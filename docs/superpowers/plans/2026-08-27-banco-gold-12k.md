# Banco GOLD 12K Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Producir, integrar y desplegar 12,000 preguntas GOLD rigurosas para las últimas 48 horas de preparación.

**Architecture:** El inventario crecerá a 3,000 hechos y el generador emitirá tres variantes universales más un conjunto V/F seguro y balanceado. Un auditor lingüístico adversarial bloqueará patrones sin sentido antes de escribir los shards.

**Tech Stack:** Python 3, TypeScript, React, Vitest, Playwright, Vite y Vercel.

**Spec:** `docs/superpowers/specs/2026-08-27-banco-gold-12k-design.md`

## Global Constraints

- Única fuente: `MaterialConexionBiblica (1).pdf`.
- Cero conocimiento doctrinal o histórico externo.
- Exactamente 12,000 preguntas GOLD y 3,000 hechos.
- Tres tipos visibles; V/F sin huecos y sin sustituciones libres.
- Preservar historial local y compatibilidad del perfil `final-v7`.
